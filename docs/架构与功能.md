# CodeLink 架构与功能

[返回项目首页](../README.md)

当前仓库为文档预览，程序源码和安装包暂未上传。本文说明本地开发项目的实现方向与使用边界。

## 两台电脑分别做什么

### 电脑 A：开发和控制入口

A 运行本地 Codex、OpenSSH 客户端及 A 控制器。控制器导入 B 的连接信息、核验主机身份、维护应用专用 SSH 配置，并打开真实交互式终端。

每台 B 的设备记录、别名、主机信任、状态、检查与终端分别管理。网络失败使用有限重试；认证失败或指纹变化停止自动重试。

应用不要求改写用户全局 SSH 配置。实际调用需要显式使用应用维护的配置和对应设备别名。A 不安装或管理 FRP 客户端；分配工具作为独立工具使用。

### 电脑 B：工程与工具所在的位置

B 运行代理、Windows OpenSSH Server 和对应隧道客户端。代理管理环境检查、公钥授权、SSH 与隧道生命周期，并在核验后提供连接信息。

远程日常登录采用普通账户。账户能读写哪些目录、调用哪些工具，受 Windows 权限和用户授权限制。B 不需要安装 Codex、Node.js 或 OpenAI 组件。

首次部署遇到现有 SSH 服务、配置或同名账户时，需要按支持范围处理，不通过删除原有配置来强行接管。

## 信息怎样交接

| 信息 | 目的 | 处理方式 |
|---|---|---|
| A 的 SSH 公钥 | 让 B 授权 A 登录 | 交给 B 所有者部署；私钥留在 A |
| B 设备标识 | 分配对应设备的隧道 | 用于绑定和配置校验 |
| 隧道绑定包 | 让 B 准备客户端与运行配置 | 可能包含运行凭据，不能放到公开仓库 |
| 连接 JSON | 让 A 知道 B 的地址与可信身份 | 核验后经可信渠道交付，不含运行 Token 或私钥 |

连接 JSON 的字段为 deviceName、host、port、username、hostFingerprint、connectionType、provider。它是连接信息，不是部署凭据，也不包含工程根目录。

每台 B 使用独立隧道和端点。显式共享账号运行凭据模式只适用于所有者信任的设备，不能据此宣称平台凭据已实现单隧道权限隔离。

## 远程开发如何进行

打开 SSH 终端后，先查询远端身份并确认授权目录。文件通过 SFTP/SCP 传输，开发工具通过明确的远端命令运行。

本地 Codex 的文件读取和命令执行不会因为打开 SSH 终端而自动迁移到 B。应使用设备说明的配置和命令来指定远程目标。

长时间构建在 B 保存完整日志、退出状态和产物，再由 A 查询或取回结果。自动化程度与具体工程有关；当前尚未完成所有工程通用的一键编译、调试或烧录工作台。

## 服务商适配

| 类型 | 当前实现范围 | 待验证范围 |
|---|---|---|
| ChmlFrp | A 识别、B 适配与分配工具；有历史单机公网记录 | 新版本完整交互、长会话、大文件与真实多机 |
| LoCyanFrp | A 识别、B 适配与分配工具；有本机和离线验证 | 真实公网流程 |
| NATAPP | 原连接格式和已保存安装的兼容路径 | 不能把兼容旧配置推定为所有新场景可用 |
| 通用 TCP-SSH | A 经明确确认可接入标准端点 | B 未实现的适配器不会自动可用 |

平台节点、账号权限、配额和带宽由对应服务提供方决定。CodeLink 不提供穿透服务器。

## 停止、撤销和恢复

- A 端断开：停止本应用在 A 管理的终端和连接检查。
- B 端停止：按所有者意愿停止远程访问，并持久化停止意愿。
- B 端恢复：由所有者明确执行；不是无限自动重连。
- 撤销授权：与暂时停止不同，恢复需要重新满足授权条件。
- 主机指纹变化：重新通过可信渠道核实，不自动沿用旧信任。

安装、覆盖升级和卸载需分别验证配置、授权与用户数据的保留规则。单个历史版本的实测不能替代所有后续版本。

## 技术组成

本地工程采用 C#、.NET 10、WPF/MVVM、Windows OpenSSH 和 Inno Setup，分离协议、基础设施、部署、后台服务、UI 与测试。

自包含发布减少运行时安装步骤，但 Windows 系统组件、OpenSSH、隧道节点和远端工具链仍有各自前提。全新源码检出的依赖准备和构建复现属于后续公开源码前的工作。
